# Detecting Logical Fallacies

When evaluating an argument or strategy, audit the reasoning using these six diagnostic questions:

- **Evidence Check:** What factual evidence directly supports this claim?
    
- **Causation Check:** Does the data prove true causation or merely indicate correlation?
    
- **Data Check:** Is the underlying sample size and data sufficient to draw this conclusion?
    
- **Incentives Check:** Who benefits if this argument is accepted?
    
- **Alternatives Check:** Could there be another explanation for the observed results?
    
- **Counter-Example Check:** Can a valid counter-example be constructed to test the logic?
