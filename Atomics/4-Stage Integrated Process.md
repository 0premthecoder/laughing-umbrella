# 4-Stage Integrated Process

Integrated Process between [[Creative Problem Solving (CPS)]] and [[Critical Thinking (CT)]]


STAGE 1: PROBLEM FRAMING
- CPS: Generates alternative ways to view the problem
- CT: Evaluates frame validity and identifies assumptions.

STAGE 2: IDEA GENERATION
- CPS: Brainstorming, SCAMPER, Lateral Thinking. 
- CT: STRICTLY PROHIBITED (defer judgment to avoid killing divergent options).

STAGE 3: EVALUATION & SELECTION
- CT: Analyzes evidence, logical consequences, biases, and Toulmin argument structures.
- CPS: Minimal role (ideas evaluated, not generated).

STAGE 4: IMPLEMENTATION 
- CT: Stress-tests assumptions via pre-mortems. 
- CPS: Reframes execution obstacles as design challenges.
