# Conventional Thinker vs Integrated Thinkers

Convention thinking works great for well defined problems with known solution but for ill-will we need to invent Problems which can be done through Integrated thinking

| **Conventional Thinkers**                          | **Integrative Thinkers**                                     |
| -------------------------------------------------- | ------------------------------------------------------------ |
| Focus only on a few relevant features              | Consider a rich, broad set of features                       |
| Assume simple, linear causality ($A \to B$)        | Account for multi-directional, non-linear relationships      |
| Solve sequentially by breaking into isolated parts | Analyze holistically, viewing parts within the entire system |
| Choose from existing available options             | Create a novel third option                                  |
