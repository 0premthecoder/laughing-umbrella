# Core loop

[[Reinforcing Feedback Loop]]

[[Balancing Feedback Loop]]

|**Feedback Type**|**Logic**|**Typical Behavior**|**Business Example**|
|---|---|---|---|
|Reinforcing loop (R)|Change amplifies further change|Growth, decline, snowballing, network effects|More users attract more complementors, which attract still more users on a digital platform|
|Balancing loop (B)|Change triggers correction toward a goal or constraint|Goal seeking, adjustment, stabilization, oscillation with delays|Inventory gap triggers orders; incoming supply reduces the gap|
|Delayed feedback|The effect arrives after a lag|Overshoot, oscillation, instability|Retailers over-order because the supply response is delayed|
|Competing loops|Several loops operate simultaneously|Early growth followed by slowdown|A startup's demand grows through word-of-mouth but service capacity becomes a constraint|
