# Linear Problem Solving vs. Systemic Diagnosis

Conventional management often relies on **linear problem solving**—assuming direct, immediate, and proportional cause-and-effect relationships. 

**Systems thinking** shifts focus to underlying structures, feedback loops, interdependencies, and delays that produce repeating patterns over time.

```mermaid
graph TD
    subgraph Linear ["Linear Problem Solving"]
        L1["<b>Event / Symptom</b>"] --> L2["<b>Direct Cause</b>"]
        L2 --> L3["<b>Quick-Fix Solution</b>"]
        L3 -.->|Unintended Side Effects| L1
    end

    subgraph Systemic ["Systemic Diagnosis"]
        S1["<b>Observed Patterns / Trends</b>"] --> S2["<b>Underlying Systemic Structure</b>"]
        S2 --> S3["<b>Mental Models & Interdependencies</b>"]
        S3 --> S4["<b>High-Leverage Structural Intervention</b>"]
        S4 -->|Feedback Loop| S2
    end
```
