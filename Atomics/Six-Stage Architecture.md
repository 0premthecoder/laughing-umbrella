# Six-Stage Architecture

Frame $\rightarrow$ Sense $\rightarrow$ Generate $\rightarrow$ Judge $\rightarrow$ Act $\rightarrow$ Learn.

- _AI Strengths:_ Scale search, pattern recognition, simulation, evidence retrieval, continuous monitoring.
        
- _Human Strengths:_ Framing, setting purpose, contextual interpretation, value trade-offs, empathy, ultimate accountability.
        
    - _Overlap:_ Alternative/scenario generation.
