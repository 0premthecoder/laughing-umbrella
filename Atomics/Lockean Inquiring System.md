# Lockean Inquiring System

The Lockean Inquiring System derives from the British Empiricists 
John Locke (1632-1704),
George Berkeley (1685-1753),
David Hume (1711-1776).

Truth is experiential
Data Input is not Only prior to the Formal theory/Model - it is independent of it
Inductive logic rules; patterns in observations generate general conclusion 

Emphasis on Raw Data and Experiments
Theory/Model derived from or tested against data = Reverse of [[Leibnizian  Inquiring System]]
Most Powerful when data is abundant, reliable and representative
Hallmark Question: "What does the evidence show? What is the probability of error?"
