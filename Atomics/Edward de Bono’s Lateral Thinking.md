# Edward de Bono’s Lateral Thinking

- **Concept:** Grounded in the insight that the brain is a self-organizing pattern-recognition system that gets trapped in self-reinforcing logical routines (_vertical thinking_). Lateral thinking provides formal tools to deliberately disrupt these patterns.

```mermaid
graph TD
    Root["Lateral Thinking Tools"] --> T1["<b>1. Random Entry</b><br>Force-connect an unrelated word/object to the problem.<br><i>Ex: Loyalty Program + 'Lighthouse' ➔ 24/7 visible commitment signals & proactive hazard alerts.</i>"]
    Root --> T2["<b>2. Provocation (PO)</b><br>State an absurd setup to extract a new principle.<br><i>Ex: 'Cars have square wheels' ➔ Variable stiffness suspension & speed bump designs.</i>"]
    Root --> T3["<b>3. Challenge</b><br>Question long-held norms without assuming incompetence.<br><i>Ex: 'Why do banks need branches?' ➔ Digital Banking.</i>"]
    Root --> T4["<b>4. Concept Extraction</b><br>Strip an innovation to its core principle and apply elsewhere.<br><i>Ex: Gillette Razor/Blade Model ➔ SaaS, Spotify, & Adobe Subscriptions.</i>"]
```
