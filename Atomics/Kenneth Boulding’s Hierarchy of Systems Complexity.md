# Kenneth Boulding’s Hierarchy of Systems Complexity

| **Level** | **System Type**          | **System Characteristics**                       | **Business / Organizational Example**                         |
| --------- | ------------------------ | ------------------------------------------------ | ------------------------------------------------------------- |
| **1**     | **Frameworks**           | Static structures, no real-time movement         | Org charts, balance sheets, factory floor layouts             |
| **2**     | **Clockworks**           | Simple dynamic systems with predictable motion   | Assembly lines, automated monthly payroll processing          |
| **3**     | **Thermostats**          | Cybernetic, self-regulating control loops        | ERP inventory reorder systems, climate-controlled warehousing |
| **4**     | **Open Systems**         | Self-maintaining, active environmental exchange  | A startup acquiring capital/talent; a franchise unit          |
| **5**     | **Genetic-Societal**     | Differentiated parts with a shared blueprint/DNA | Toyota Production System (shared lean culture/DNA)            |
| **6**     | **Animal Systems**       | Mobility, specialized sensors, goal-directed     | Agile product squads, "SEAL-team" startup units               |
| **7**     | **Human Systems**        | Self-consciousness, language, culture, values    | Creative agencies, family businesses, partnerships            |
| **8**     | **Social Organizations** | Shared meaning, loose coupling, complex roles    | Multinationals, trade unions, NGOs, industry clusters         |
| **9**     | **Transcendental**       | Ultimate unknowables, emergent VUCA complexity   | Global financial markets, evolution of the internet economy   |
