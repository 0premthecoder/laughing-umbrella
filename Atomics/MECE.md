# Core SCR Concepts

#### 1. The MECE Principle

- **Mutually Exclusive:** Each branch or element covers a distinct, non-overlapping domain (zero double-counting).
    
- **Collectively Exhaustive:** All elements together cover 100% of the problem space (zero gaps).
    
- **P&L Breakdown Example:** Decomposing revenue drop into:
    
    $$\text{Revenue Change} = \text{Volume Effect} + \text{Pricing Effect} + \text{Product Mix Effect}$$
    
    _(These 3 factors account for 100% of revenue variance without overlapping)._

#### 2. Issue Trees & Logic Trees

Visual tools designed to break complex problems into MECE components:

- **Diagnostic Trees (Why Trees):** Used to isolate root causes.
    
- **Solution Trees (How Trees):** Used to map out tactical paths.
    
- **Hypothesis Trees:** Decomposes a main hypothesis into testable, MECE sub-hypotheses.
