# Irrelevant Validation Fallacies

- **Bandwagon Fallacy:** Claiming a strategy is correct because competitors or many people subscribe to it (e.g., investing in the metaverse strictly because rivals are doing so).
    
- **Appeal to Tradition:** Assuming a process is optimal simply because it has been used for a long time (e.g., resisting e-commerce because traditional retail worked for decades).
    
- **Appeal to Novelty:** Assuming an approach or tool is superior purely because it is new (e.g., buying a new AI tool expecting automatic performance gains).
    
- **Appeal to Emotion:** Relying on feelings (sympathy, pride, loyalty, fear) instead of data (e.g., refusing to cancel a failing initiative because _"the team worked so hard on it"_).
    
- **Sunk Cost Fallacy:** Justifying further expenditure on a failing project based on past investments rather than future ROI potential.
