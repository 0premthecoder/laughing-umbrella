# System Theory

Systems Theory provides a unified framework to explain complex, organized wholes that operate across diverse domains (biology, engineering, economics, management). In management, it functions as both a **descriptive** (explaining organizational phenomena) and **prescriptive** tool (guiding structural interventions).
