# Common Resources

Rival in Consumption but not excludable 

These are available free of Charge but one person consumption Reduced Availability of Others 

No One Own something so no one has incentive to conserve it

Each users imposes a [[Negative Externalities]] on others but doesn't bear the cost = Over use 
- tragedy of commons
