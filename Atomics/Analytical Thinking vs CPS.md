# Analytical Thinking vs CPS

| **Dimension**         | **Analytical Thinking**                          | **Creative Problem Solving (CPS)**                   |
| --------------------- | ------------------------------------------------ | ---------------------------------------------------- |
| **Problem Type**      | Well-structured, bounded, data-rich              | ill-structured, ambiguous, novel, contested          |
| **Dominant Question** | _"What is the correct answer?"_                  | _"What are better ways to define & solve this?"_     |
| **Primary Logic**     | Deductive/Inductive, Root Cause, Optimization    | Divergent, Reframing, Analogies, Synthesis           |
| **Output Type**       | Single recommendation based on data/facts        | Portfolio of possibilities, prototypes, experiments  |
| **Example**           | Calculating optimal inventory reorder quantities | Inventing service/subscription models for non-owners |
