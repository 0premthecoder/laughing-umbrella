# Inquiry System


| **System**     | **Philosopher**               | **Logic**             | **Nature of Truth**                         | **Suited For**                                       |
| -------------- | ----------------------------- | --------------------- | ------------------------------------------- | ---------------------------------------------------- |
| **Leibnizian** | Leibniz / Descartes / Spinoza | Deductive             | **Analytic:** derived from axioms           | Well-defined, analytical problems                    |
| **Lockean**    | Locke / Berkeley / Hume       | Inductive             | **Experiential:** grounded in data          | Well-defined, experimental problems                  |
| **Kantian**    | Immanuel Kant                 | Multi-model synthesis | **Synthetic:** theory + data fused          | Definable problems with clear objectives             |
| **Hegelian**   | Hegel                         | Dialectical           | **Conflictual:** thesis vs. anti-thesis     | Ill-defined, opposing-objective problems             |
| **Singerian**  | E.A. Singer / Churchman       | Teleological          | **Pragmatic:** guided by purpose and ethics | Ill-defined, multidisciplinary, value-laden problems |
