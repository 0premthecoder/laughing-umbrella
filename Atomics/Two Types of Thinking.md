# Two Types of Thinking

| **Decisive Thinking**                           | **Incisive Thinking**                                      |
| ----------------------------------------------- | ---------------------------------------------------------- |
| **Left-Brain Dominant**                         | **Right-Brain Dominant**                                   |
| Factual, objective; trusts a frame of reference | Intuitive, acumen-led; spots trends and predictive signals |
| Less trend-dependent; more stable across cycles | Synthesizes rather than decomposes                         |
| Compares options and evaluates outcomes         | Recognizes “pattern vectors” across domains                |
| Provides a framework for analysis               | Provides a framework for interpretation                    |
