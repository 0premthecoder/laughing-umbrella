# Functional vs Integrative Management


| **Functional management**      | **Integrative management**                                 |
| ------------------------------ | ---------------------------------------------------------- |
| Optimizes a department         | Optimizes an end-to-end value system                       |
| Assumes boundaries are stable  | Treats boundaries as design choices                        |
| Seeks the best answer          | Seeks a coherent and adaptable portfolio of actions        |
| Resolves tension by compromise | Uses tension as input for synthesis                        |
| Views technology as a tool     | Views technology as part of the socio-technical system     |
| Controls variance              | Distinguishes harmful variance from useful experimentation |
