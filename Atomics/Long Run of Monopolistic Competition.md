# Long Run of Monopolistic Competition

Zero Economic Profit in Long Run

If firms earn profits -> new entrants -> each
firm's demand decreases

If firms suffer losses -> some exit -> remaining
firms' demand increases

Process continues until economic profit = 0

Outcome: Price = Average Total Cost (but still
above MC)
