# SCAMPER

 Developed by Bob Eberle (condensing Alex Osborn’s 75 questions into a 7-letter checklist). Forces systematic variations around an existing product, service, or business process.

| **Letter** | **Action Prompt**             | **Corporate Application / Example**                                                                                             |
| ---------- | ----------------------------- | ------------------------------------------------------------------------------------------------------------------------------- |
| **S**      | **Substitute**                | **Tesla:** Substituted Internal Combustion Engines with electric motors, shifting value to software and energy.                 |
| **C**      | **Combine**                   | **Smartphones:** Combined phone, camera, GPS, web browser, and music player into one unit.                                      |
| **A**      | **Adapt**                     | **Velcro:** Adapted hook-structures from burr plants. **ARM Chips:** Adapted RISC architecture to mobile.                       |
| **M**      | **Modify / Magnify / Minify** | **Pharma Micro-dosing:** Miniaturized drug doses to reduce toxicity while preserving therapeutic efficacy.                      |
| **P**      | **Put to Other Uses**         | **Amazon AWS:** Transformed internal IT infrastructure into a public cloud platform (drives ~62% of operating profit).          |
| **E**      | **Eliminate**                 | **Ryanair:** Eliminated free meals, seat numbers, luggage allowances, and travel agents to build ultra-low-cost aviation.       |
| **R**      | **Reverse / Rearrange**       | **IKEA:** Reversed supply chain by having customers assemble flat-pack furniture. **Zara:** Inverted fashion cycles to 3 weeks. |
