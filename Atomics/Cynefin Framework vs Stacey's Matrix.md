# Cynefin Framework vs Stacey's Matrix

| **Dimension**         | **Cynefin Framework**                                      | **Stacey's Matrix**                                                |
| --------------------- | ---------------------------------------------------------- | ------------------------------------------------------------------ |
| **Core Axis**         | **Causality:** Predictability of cause-and-effect          | **2 Axes:** Degree of Certainty + Degree of Agreement              |
| **Domains / Zones**   | **5:** Clear, Complicated, Complex, Chaotic, Disorder      | **4–5:** Rational/Simple, Complicated, Political, Complex, Anarchy |
| **Key Insight**       | Different contexts require fundamentally different actions | Complexity is the creative engine where most strategy occurs       |
| **Leadership Focus**  | Sense context $\rightarrow$ match leadership mode          | Manage tension between certainty/agreement; enable emergence       |
| **Primary Use Cases** | Crisis management, org strategy, knowledge mgmt            | Strategic planning, innovation, org change, team alignment         |
| **Danger Zones**      | Disorder; misdiagnosing complex as complicated             | Anarchy; over-controlling complexity; under-managing chaos         |
| **Key Tools**         | Narrative inquiry, safe-to-fail experiments, sensemaking   | Shadow networks, informal systems, minimum specs                   |
| **Best Applied For**  | **Diagnosing** a situation before deciding how to act      | **Designing** conditions for innovation and adaptation             |
